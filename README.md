# MTG Art Game

A Next.js prototype for a game where you guess which Magic: The Gathering card art is older.

## What it does

- Shows two card-art prompts side by side.
- Lets the player choose which card art appears first in Magic history.
- Tracks score, streak, and round feedback.
- Uses local sample data so the app works without an API.

## Run it

```bash
npm install
npm run dev
```

## Build it

```bash
npm run build
```

## Notes

The current card set is placeholder data for the game loop. Replace it with your preferred MTG card catalog or API source when you are ready.
